# boxitlogistics.co.uk

Static website for Boxit Logistics & Storage — removals, storage, handyman and CCTV services in Walsall, West Midlands.

Internal setup and configuration documentation lives outside this repository (it is deployed as-is to the live site).

## Development

- `npm install` then `npm run build:css` regenerates `assets/tailwind.css` after adding new utility classes to HTML/JS.
